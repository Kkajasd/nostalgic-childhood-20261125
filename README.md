One sentence that brings back a childhood memory: a grandmother's kitchen smelling of fried garlic and steamed rice, a child sitting on the cold tile floor stealing warm grains straight from the pot while she pretended not to notice. The program writes that one sentence (183 characters, no trailing newline) to `/output/entry.txt`.

The sentence is fixed at author time — no clock, no randomness, no network — so every run writes byte-identical output and passes the 1–280 character gate deterministically.

## Run it

```sh
node main.ts
```
